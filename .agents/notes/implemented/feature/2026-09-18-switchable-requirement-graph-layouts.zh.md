# Agent Note: 可切换需求图谱布局

Status: implemented

[English](2026-09-18-switchable-requirement-graph-layouts.md) | 中文

## Problem

一种固定编排无法让密集的四层 Session 图谱在所有观察目标下都保持清晰。用户可能需要查看按层推进的顺序、定位以关系为中心的簇、比较整体连接性，或沿紧凑边界追踪跨层连线，同时不能丢失当前图谱探索状态。

## Decision

需求图谱通过“分层 · 曲线”和“径向 · 同心环”呈现同一组可见节点与有向边。分层模式保留固定透视平面、有序行和从上向下的曲线连接。径向模式把文档节点置于圆心附近，把具体需求、Task 和代码节点放在逐级扩大的圆环上。[双视图控制决策](../simplification/2026-09-19-two-mode-graph-toggle.zh.md)负责圆形切换按钮，以及应力和扇区环形呈现的移除。

每种呈现都使用以节点中心为基准的坐标、自有画布范围、随密度调整的节点比例、背景区域和预先计算的 SVG 边路径。渲染器把连线端点偏移到节点外环附近并保留方向标记。图谱会把当前范围等比适配到侧栏宽度，仍可手动缩放和滚动。这些包内算法复现选定的 ELK 与 Cytoscape 视觉类型，不嵌入这两个布局引擎，也不声称正在运行它们。

切换呈现会保留展开状态、搜索文本与结果、轮次筛选、选中节点与详情内容、缩放以及详情区比例。系统重新计算几何与边路由后，会把已选节点带回可见区域；没有选中节点时则回到画布原点。切换 Session 会重新挂载带 key 的图谱面板，因此布局会与其他 Session 本地视图默认值一起恢复为“分层 · 曲线”。[渐进式需求图谱决策](2026-09-17-progressive-requirement-graph.zh.md)继续负责展开、搜索、共享节点可达性和详情；本决策负责共享布局几何。

## Alternatives considered

**嵌入 ELK 与 Cytoscape 布局运行时。** 予以放弃，因为两个独立图谱引擎会增加大量浏览器代码和结果协调，同时仍需产品专属的语义排序、背景区域、DOM 节点集成和后处理。确定性的本地算法能够提供所需视觉类型，也不会暗示不存在的引擎。

**自动选择一种自适应布局。** 予以放弃，因为任何密度启发式都无法知道用户是在比较层级、追踪关系簇、检查整体连接性还是减少交叉。明确的切换按钮让用户控制空间解释方式。

**使用无约束的随机力导向模拟。** 予以放弃，因为位置会在不同渲染和 Session 间漂移，导致图谱快照、空间记忆和浏览器回放不可靠。确定性几何让节点位置可以复现。

## Consequences

布局切换始终是本地视图状态，不发起模型请求或修改 Session。两种呈现共享同一组 Session 节点与有向边、展开模型、节点编号、选择和详情。径向呈现使用更大的方形范围，狭窄侧栏可能需要缩放或滚动；密集图谱会缩小节点而不是丢弃节点。确定性几何支持聚焦单元测试、组件状态保留测试和无需密钥的浏览器回放。新增呈现时，必须扩展封闭的布局模式列表、类型化 locale 文案、纯几何模块、渲染区域以及相同的状态保留覆盖。

## Testing

纯布局测试覆盖确定且有限的坐标、范围内节点中心、背景区域类型、默认分层几何、径向圆环顺序、边路径和空图。组件测试依次切换两种呈现，同时保留已展开节点、搜索、轮次筛选、选择、缩放和详情区尺寸，并验证 Session 变化会恢复默认布局。无需密钥的 Web 导航回放在全部展开的 Session 图谱上操作切换按钮的两种状态，并保留已选代码详情。
