# Agent Note: 人类指令驱动的任务文本

Status: implemented

[English](2026-09-15-human-directed-task-text.md) | 中文

## Problem

用户编辑 Notebook 说明是为了改变 Agent 的任务。仅用于展示的说明会让 Agent 继续执行旧指令。在一次回复中生成执行文本和人类说明，也无法强制保证两者的生成顺序。

## Decision

宿主先校验技术任务，再由独立且无工具权限的子 Agent 翻译标题与说明。翻译必须原样返回执行文本。人类编辑则让子 Agent 重写完整执行说明，宿主将人类原文同时保存为展示说明和持久字段 `humanInstruction`。执行和审核优先遵守该指令而非冲突的旧需求。

人类编辑区在失焦或执行前保存。每个 Task 的保存串行进行，后续草稿基于已提交的执行文本继续修改。宿主在合并到最新列表前重新检查被编辑 Task 和源文档。其他 Task 保存成功不会使当前 Task 的翻译失效，但目标 Task 被修改或撤回仍会使其失效。检查整个列表修订会拒绝有效的批量保存，而提交旧列表会覆盖其他 Task 的编辑。失败或陈旧的转换保留旧持久任务，并在编辑器显示错误。成功编辑会重新打开任务和已完成的 Final Test，并使旧验证证据失效。

本决策替代 [Notebook 流程说明](2026-09-02-requirement-notebook-pipeline.zh.md)中的同次回复翻译和仅展示用途的说明编辑选择。该说明继续负责 Notebook 标识、证据展示和被动备注语义。

## Alternatives considered

**在任务生成回复内翻译。** 可节省请求，但无法强制保证翻译读取已确定的任务。独立子 Agent 允许宿主检查执行文本是否原样保留。

**只修改展示摘要。** 可避免模型延迟，但不符合用户通过编辑指挥 Agent 的预期。

**每次按键都重写。** 会对未完成的指令发起请求。失焦和执行是明确的提交时点，后续编辑排队处理且不覆盖最新本地文本。

## Consequences

每个生成任务或非空任务编辑会通过配置的提供方增加一次子 Agent 调用。完整提示词必须符合配置的输入上限，宿主拒绝截断。机械检查约束生成说明的语言、长度、句数和技术噪声，但无法证明语义忠实度。用户原文不受生成摘要长度上限限制。未确认保存的草稿仍仅保留在当前标签页。

## Testing

宿主测试覆盖人类优先、重新打开任务、过期结果拒绝、无效翻译和失败不改写持久状态。浏览器测试覆盖直接编辑、保存结算和刷新。任务文本录制场景通过真实 Web 组合测试翻译和人类指令改写，录制使用真实提供方，随后支持无密钥重放。
