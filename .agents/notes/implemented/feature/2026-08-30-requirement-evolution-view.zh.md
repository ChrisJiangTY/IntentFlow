# Agent Note：需求演化视图

状态：已实现

[English](2026-08-30-requirement-evolution-view.md) | 中文

## 问题

“对话”记录用户和 Agent 说了什么，“轨迹”记录 Agent 如何工作，但两者都无法展示需求如何在多轮交互中逐渐清晰或发生变化，也无法独立判断当前代码是否支持最终需求集。把每条用户消息当成独立需求会丢失细化历史；把助手的完成声明当成证据则会让验收变成自我报告。

## 决策

Web 对话新增“需求”视图。每个父会话轮次结束后，一个一次性子 Agent 接收上一份审核快照，以及当前轮次的用户、助手、计划和工具证据。它把用户 prompt 作为主要需求证据，保持稳定的需求标识，对每个版本分类，并在设置审核状态前检查当前工作区。子 Agent 仅允许位于第一层委派深度，并只获得明确配置的只读工具，因此不能继续委派。当前 Notebook 呈现记录在[需求 Notebook 流程说明](2026-09-02-requirement-notebook-pipeline.zh.md)中。

每次审核都向父会话追加一份完整的 `requirement/review` 快照。版本 2 会把审核者生成的标题、表述、来源摘要、代码观察、审核摘要和缺口同时存为简体中文与英文。旧快照保持不变，因此客户端可以比较相邻版本，无需从当前状态重建历史；版本 1 的纯字符串会保留显示，浏览器不会虚构翻译。失败审核会追加失败记录，不虚构需求或代码证据。自动审核与手动审核共用同一条按会话串行的执行路径。

用户运行的需求单元是另一类事实来源。`requirement/user-version` 会在 Agent 开始执行前，以稳定需求标识和单调版本号记录用户原样输入的标题与正文。生成的 `sessionRequirements.commit` Remote 会拒绝过期修改、追加该持久版本，并排入一条普通用户消息；消息只描述所选变化，并保持其他需求不变。`requirement/execution` 独立记录处理中、完成或失败；执行失败永远不会回滚用户版本。审核者必须保留用户版本行的标识与原语言文本，但代码证据和审核状态仍完全由审核者负责。

审核投影保留稳定需求标识、用户拥有的表述、审核者双语内容、来源引用、代码证据、审核结论和独立执行状态。当前浏览器呈现与产品轮次流程由[需求 Notebook 流程说明](2026-09-02-requirement-notebook-pipeline.zh.md)维护；本说明记录的审核与用户版本协议仍是它的宿主基础。

## 考虑过的替代方案

**一条用户消息等于一条需求。** 不采用，因为后续 prompt 经常会细化、收窄、替换或撤回早期意图。

**固定展示需求、文件与日志三栏。** 不采用，因为它让辅助信息获得同等视觉权重，反而遮蔽最主要的问题：需求随时间发生了什么变化。

**让主 Agent 维护完成状态。** 不采用，因为变更作者不是独立验证来源。助手回复和计划仍可作为解释来源，但不能证明完成。

**完全在浏览器中推导视图。** 不采用，因为浏览器推导既不持久，也无法独立审核，而且每次重新加载历史都会重复模型工作。

**只在读者切换语言时翻译。** 不采用，因为浏览器运行时的模型翻译会增加延迟，在重复阅读时产生不同表述，也无法为持久审核记录留下精确的双语版本。

**用独立 Notebook 布局替换“需求”视图。** 不采用，因为时间主轴和需求—代码关系投影已经回答全局演化问题。Notebook 交互应进入现有需求卡片，而不是建立新的页面层级。

**用户输入时自动发送。** 不采用，因为未完成草稿不是已确认需求。显式运行单元会形成一个明确持久版本边界和一条精确主 Agent 消息。

## 结果

用户确认的表述不再是审核者判断；翻译、变化分类与实现证据仍是模型判断，并与用户事实清晰分开。每个父轮次仍会触发一次辅助审核请求，用户版本仍通过只追加事件保持可追溯。Notebook 的当前界面取舍与 Task 操作见[需求 Notebook 流程说明](2026-09-02-requirement-notebook-pipeline.zh.md)。

## 测试

宿主测试覆盖双语审核执行、用户版本新增与修改、过期版本拒绝、精确主 Agent prompt、执行状态转换与失败记录。客户端测试把审核、用户版本和执行转换保存在分开的有序投影中，并证明两条草稿会同时保留，而运行其中一条只提交它自己的需求。构建产物 HTTP smoke 会实际穿过生成的需求 Remote。无密钥 Web 快照固定中英文内容、明确的编辑与运行控件、紧邻的扁平加号几何关系，以及有效但未提交的单元草稿。仓库类型、文档、客户端文案、配置与持久化 gate 覆盖包级接入。
