# Agent Note: 渐进式四层需求图谱

Status: implemented

[English](2026-09-17-progressive-requirement-graph.md) | 中文

## Problem

全部展开的 Session 图谱难以说明哪一轮对话引入了需求。用户需要只探索相关工作，同时保留共享 Task 和文件，并找到父级分支仍被折叠的代码。

## Decision

侧栏图谱在同一画布中呈现四个紧凑有向层级：轮次文档、具体需求、Task、修改文件。默认的“分层 · 曲线”呈现保留四个 SVG 透视平面，其倾角、间距、顺序和尺寸固定，不受节点数量影响。平面采用各层对应的淡彩填充和细透视网格。各层节点保持图谱数据顺序，居中均衡分行，每行最多十五列。换行沿透视斜率小幅偏移。节点比例同时考虑横向间距和行深度；20 个需求与 27 个 Task 各占两行，41 个文件占三行。Task 和代码球体的基础尺寸接近需求球体。蓝色三次曲线的端点切线保持垂直，控制距离随纵向间隔等比变化。侧栏宽度决定画布的等比缩放，也支持放大到基础尺寸以上。固定面积下密集节点尺寸会减小，可通过搜索与收起分支聚焦节点。

圆环节点显示 Session 内各层的顺序编号，不受折叠和筛选影响，使用 Figma 文件 `JastOBEf9QnfNAqGqyaSIR` 中节点 `45:2` 的无损内嵌素材；标题保留在悬停提示、可访问名称和详情区，不占用画布。顶部搜索和轮次筛选靠左，“全部展开”靠右，显示当前轮次筛选范围内的全部节点，包括未关联需求的 Task，不虚构连线。缩放位于图谱控制行右侧。文档节点使用稳定轮次标识。

详情区默认预留 30% 内容高度，节点选择前后保留当前比例。可访问的横向分隔线在 15–60% 之间调节预留空间；调节时只改变图谱可见区域，不改变缩放比例或平面几何。搜索结果覆盖显示，不改变画布高度。内容始终显示，仅保留靠右的紧凑 Notebook 定位操作。[可切换图谱布局决策](2026-09-18-switchable-requirement-graph-layouts.zh.md)负责共享布局几何；本决定继续负责渐进展开、搜索、共享节点可达性与详情。[Session 图谱决策](2026-09-16-session-requirement-code-graph.zh.md)继续负责修改归属、Session 范围和片段存储。

默认只显示文档。点击节点只打开详情，不改变可见性；其 `+`/`−` 展开控件可独立展开或收起下一层。可见性从文档根节点沿已展开的出边计算；只要仍存在可达的已展开路径，共享节点就会保留。收起分支会清除不可达后代的展开状态。选择节点高亮有向祖先和后代，不直接跳转 Notebook。详情中的明确操作定位文档、需求标题或 Task；文件操作打开侧栏查看器。

搜索覆盖全部图谱节点，包括折叠节点及被轮次筛选隐藏的节点。选择结果会清除轮次筛选并展开全部祖先路径。未关联 Task 可成为明确的搜索根节点，不虚构需求连线。实时更新保留展开选择、更新计数与状态，不自动打开折叠分支。全部关联 Task 已完成的需求显示“待终验”，权威状态仍为“进行中”；只有既有最终验证投影能将其验证。

## Alternatives considered

**自由视角 3D。** 予以放弃，因为旋转文字和节点遮挡影响侧栏阅读。默认的固定透视保留层级纵深，并使用支持键盘的普通控件。

**严格树式展开。** 予以放弃，因为 Task 和文件可能有多个父节点。可达性保留单个共享节点及其不同有向连线。

**仅搜索可见卡片。** 予以放弃，因为查找隐藏代码前不应要求用户先知道所属需求。

## Consequences

展开、搜索、筛选、布局选择、平移与缩放都是本地视图状态，不发起模型请求或修改 Session。轮次筛选不会清除其他轮次的展开选择。侧栏调宽仍由插件负责。画布独立滚动并支持减少动画偏好。文件片段是历史证据，不代表当前文件内容或测试通过。搜索索引文档文本、需求标题及验收引用、Task 描述和文件路径，不索引片段内容。密集图谱仍需滚动或缩放。

## Testing

组件测试覆盖默认仅文档、逐层展开、共享节点收起、搜索祖先、未关联 Task、轮次筛选、实时新增、终验状态、明确导航和代码证据转义。无需密钥的 Web 导航回放验证侧栏入口、全部四层、延迟到达的修改、折叠代码搜索和画布滚动，并保留图谱可访问性快照。
