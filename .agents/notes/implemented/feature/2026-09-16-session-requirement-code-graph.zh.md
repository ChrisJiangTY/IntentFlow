# Agent Note: Session 需求代码图谱

Status: implemented

[English](2026-09-16-session-requirement-code-graph.md) | 中文

## Problem

用户需要把一次对话中的需求、可执行 Task 和实际代码修改连接起来。Workspace 需求关系不能说明哪个 Task 修改了文件。审核者的文件引用可能来自读取或已有实现，不能证明发生过修改。

## Decision

需求图谱是一个按 Session 隔离的 `dsh-better-sidebar` 标签页，并在该 Session 变为活动状态时成为默认标签页。仅指定类型的默认打开不会展开已关闭的右侧栏。随后明确打开内容时可聚焦对应文件或浏览器标签页；图谱标签页关闭后可从 `+` 菜单恢复。Web 组合包把 `dsh-better-sidebar` 固定为 `0.17.1`，并针对当前交付的 DSH `0.1.2-alpha.1` 客户端验证其所需服务方法。[渐进图谱决策](2026-09-17-progressive-requirement-graph.zh.md)负责四层呈现。未撤回的 Task 关联到匹配的文档修订。验收标准引用连接需求与 Task，Task 执行 Turn 连接 Task 与已记录修改。选择节点会高亮有向祖先和后代，不遍历兄弟分支；选择文件会展示历史修改前后片段及所属 Task。

需求客户端在 apply 层计算当前图谱。含代码片段的图谱值保留在按 Session 索引的内存 Map 中；右侧栏标签页元数据只保存单调递增的修订标记，用于请求重新渲染。适配器观察活动 Session，在身份变化时使用准确的 Session scope 执行一次仅指定类型的图谱打开。关闭的右侧栏保持关闭，同一 Session 的重复状态更新不会从其他标签页夺回焦点。Session 变化会退订旧 Notebook 数据源并重置图谱交互状态。这样不会通过右侧栏按 Session 隔离的本地存储持久化代码片段。Notebook 注册 Session 本地的定位回调，使图谱选择可以定位 Task，同时不让功能组件接触 Cordis。右侧栏浏览器已挂载且启用时，普通点击外部 HTTP 或 HTTPS Task 交付链接会在当前 Session 中打开；接管失败及带修饰键的点击保留浏览器原生行为。

宿主的 `requirementChanges` 投影回放成功的 `write`、`edit` 和修改型 `str_replace_editor` 结果。调用标识和 Turn 关联结果，已应用 diff 元数据或已确认的新建/编辑器参数提供片段。读取、失败和无变化 diff 不产生连线。完整投影在分页和重连后保留，无需单独轮询 API 或模型请求。

本决定替代[原图谱决策](2026-09-08-workspace-requirement-knowledge-graph.zh.md)中的 Workspace 聚合和呈现。原决定的文档标识、依赖验证、修订处理和 Task 派生状态继续有效。

## Alternatives considered

**严格树布局。** 共享文件保留多个 Task 父节点，不在每个 Task 下复制同一文件。

**把审核引用作为修改文件。** 予以放弃，因为被检查的代码不一定被修改，审核需求标识也不能证明 Task 修改归属。

**保留第二个由功能包自管的侧边面板。** 予以放弃，因为这会重复 `dsh-better-sidebar` 已负责的标签页关闭、横向调宽、响应式布局和浏览器标签页导航。

**把完整图谱持久化到右侧栏标签页元数据。** 予以放弃，因为元数据会写入本地存储，而图谱可能包含历史修改前后代码片段。内存图谱加小型修订标记既能触发渲染，也不会把 Session 证据重复保存到磁盘。

## Consequences

共享右侧栏负责横向调宽、标签页关闭和窄屏布局，图谱内容在标签页内纵向滚动。原 Notebook 工具栏、命令菜单、Task 菜单和内嵌图谱入口均被移除。Task 停止操作使用精确的执行消息和 Turn，仅移除该任务的排队输入并保留无关排队工作。取消审核会中断任务专属控制器并拒绝迟到结果；已取消的排队审核不会启动。停止 Task 同时停止按序推进，但不撤销代码修改。取消的 Task 使用现有失败状态，保持可重试且不增加持久状态。

图谱解释当前对话中已记录的工作。连线不证明行为正确或测试通过，Task 状态独立展示。不推断 Shell 修改、缺少父级修改记录的委派变更和符号/行号导航。片段表示历史执行，不代表当前文件内容。保留片段会增加投影负载。

## Testing

聚焦测试覆盖打开右侧栏时默认选择图谱、无更新反馈循环的 Session 重绑定、释放、确切文档修订、共享文件归属、路径聚焦、安全片段渲染、Notebook 定位、外部交付链接路由、回放及读取/失败/无变化排除。录制的 Web 导航场景直接打开右侧栏进入图谱，并在组装后的 Web 组合包中验证缺失修改证据和实时记录修改。
