# Agent Note: 双视图需求图谱切换按钮

Status: implemented

[English](2026-09-19-two-mode-graph-toggle.md) | 中文

## Problem

四种布局选项和较宽的选择器占据侧栏空间。用户需要直接访问分层与同心环视图，同时突出图谱本身。

## Decision

图谱通过左上角一个 28px 圆形图标按钮提供“分层 · 曲线”和“径向 · 同心环”。点击、Enter 或空格键可在两者之间切换。图标表示当前视图，本地化悬停提示说明当前及下一视图，按下状态表示径向模式。搜索、展开、选择、缩放与详情区尺寸保留既有行为。

应力与扇区环形布局及其几何辅助函数、样式、文案和支持行为测试均被移除。本决策取代[可切换图谱布局决策](../feature/2026-09-18-switchable-requirement-graph-layouts.zh.md)中的四选项选择器，后者继续负责共享布局几何与状态保留。

## Alternatives considered

**保留两选项下拉框。** 予以放弃，因为二选一视图切换不需要宽文本框和额外的选择步骤。

**隐藏额外模式但保留算法。** 予以放弃，因为无法访问的实现会保留代码与测试，却不提供受支持的用户操作。

## Consequences

用户放弃力导向聚类和外围扇区探索。恢复任一模式需要明确的产品决策与交互设计。保留的几何和 Session 关联不变。组件测试覆盖往返切换与状态保留；无需密钥的 Web 回放检查键盘操作、圆形按钮几何以及更新的可访问性快照。
